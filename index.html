🍌 Banana Gorilla Skull Game 🦍

チーム設定

各チームは2人（Player A＝行を選ぶ／Player B＝色を選ぶ）です。

遊び方・ルール
  • 盤面は 7×7。行は数字 1〜7、列は色（黄・赤・橙・青・緑・紫・桃）。
  • 順番に、Player A が「行（数字）」、Player B が「色」を選びカードをめくります。
  • 🍌 = 1〜3 点を獲得。
  • 💀 スカル = 自チームの得点が 0 にリセット！
  • 🦍 ゴリラ = 相手チームの得点を全て奪う！（3チーム以上なら奪う相手を選択）
  • カードの配置は毎回ランダムです。
  • 全カードをめくったら、得点が一番高いチームの勝ち！
